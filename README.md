# Discord Bot 🤖

A Discord bot I’m developing for the **SEC community** to make server management easier and help with member roles and moderation.

## Features
- Manage member roles
- Help with server moderation
- Simplify member management

*More features may be added as the project grows.*

## Built With
- Node.js
- Discord.js

## Setup

1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   cd YOUR_PROJECT_FOLDER
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Create a `.env` file and add your Discord bot token and IDs:
   ```env
   DISCORD_TOKEN=your_bot_token
   CLIENT_ID=your_client_id
   GUILD_ID=your_server_id
   ```

4. Start the bot:
   ```bash
   node index.js
   ```

**Note:** Keep your `.env` file private and never upload it to GitHub.
